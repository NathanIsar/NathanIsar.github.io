dungeon knight

Creation of a puzzle/course game on Unreal Engine 5.6.1. The goal was to learn how to effectively manage the link between C++ and Blueprints by creating a C++ interface and systems in C++ to derive Blueprints from them and create gameplay logic within the Blueprints.

Unreal Engine C++ Blueprints

Physics birds

Creation of an Angry Birds-style game on Unreal Engine 5.6.1. The goal was to learn how to effectively manage the engine's physics by implementing materials with different characteristics and then the chaos system to make them destructible. We also exploited the field system to create physical effects like an explosion and a black hole as a special ability for the birds, as well as a field to perform a dash in the levels. The physics constraint allowed us to create gameplay elements in the levels such as a drawbridge, a bumper, and others.

Unreal Engine C++ Blueprints Chaos system Fracture Field System Physics constraints/ materials
